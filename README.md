# SmartBusTracker

Application mobile Android de gestion et suivi du transport public.

## Features
- User/Admin authentication
- OpenStreetMap integration
- Realtime bus simulation
- Favorites
- Notifications
- Dark Mode
- Dynamic stations
- CRUD bus lines
- Search system

## Technologies
- Kotlin
- XML
- SQLite
- OpenStreetMap
- RecyclerView
- SharedPreferences
